### Not automatically parity requirements

`BACKLOG.md` explicitly deferred sample rename/delete UI, 16-bit sample output, automatic wav2agb installation/legacy AIF writing and device selection. `SPEC.md` mixes future ideas such as MIDI live input, keysplit-table editing and advanced roadmap items with shipped features. Preserve what actually shipped; do not add these by inference. Conversely, a stale backlog cannot demote behavior present in the C++ source. No shipped feature is removed merely because it lacks a proof ledger.

Also excluded absent contrary shipped-source evidence: shortcut remapping/browser (`docsrc/manual/shortcuts.md:3-8` explicitly rules it out), track-header volume/pan mini-sliders (manual placeholder, not the header anatomy), window-level file-drop, Recent Projects, automatic `.s`→MIDI conversion and song-package transfer. Assembly-only song **listing** is distinct from conversion: SPEC requests an import-only badge but current service/list filters them; compare the legacy list before deciding this row rather than silently treating either behavior as parity.
