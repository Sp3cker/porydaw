## Frozen focused answer key

# Frozen revision 3 focused retest key

R1: Keep Quick gate. allowsNativeInput covers native/app/effective-visibility, not Quick session. Direct bypass unsupported and not guaranteed rejected. Covered source's empty disallowed through normal host; popup admitted empty valid different source, neither value bypasses admission.
R2: Catalogue cache survives app lifetime; old source/claim ends on tab hide/detach/destruction per existing lifetime; cache cannot resurrect; new tab fresh admitted claim. A→B same profile transfers owner before signal suppression; late A clear no effect on B.
R3: both scrolling targets HorizontalScroll; track TrackScope, event EventRows distinct modifier/action sets. Share complete IDs for equal current action+modifier sets; fragments private when only parts overlap. No duplicate IDs justified by hypothetical future changes.
R4: graph m_gestureProfile captures interior ID until terminal/idle inside reclassification, outside clears; no new TimelineInputItem member, QML has existing _gestureProfile. Native fine editor zero style retains fine drag, omits accelerated wheel; DragScrub fixed Control wheel unaffected.
R5: namespace registration once processwide static once_flag, not perengine; each engine context property set again borrows same app MouseHints/catalogue. Successful build establishes C++/moc/link registration compile viability not runtime enum invocation/twoengine resolution/composed behavior; run actual scene and smoke.
R6: task4 declaration+production overrides3files, task7 two test adapters+producers; no half acceptance/shim; wording only hintprofiles.cpp, new action set newID+catalogue entry+existing target selects; no public fragment builder/centralhit/source state.
