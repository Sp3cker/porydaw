Edit Sample & Split Studio — redesign mockup

Control-set proposal. The windows show only controls and their labels: no explanatory text, no colour coding. Project: hearth-test · mus_twitter_rock.

1 · Edit Sample

  • Load → trim → loop → pitch → listen → save. In the library, click a file to preview it and double-click to load it; Listen plays the rendered sample.
  • Loop: start/end, seam verdict, Try Another Loop, Refine, Smooth seam.
  • Sample rate: the file's rate and the rate it is saved at, plus ROM size. Length, format and the technical readout are gone.
  • Fine tune, normalize and applied gain stay in collapsed Advanced.

2 · Split Studio

  • No colours: slices and mapped keys use the one accent colour; numbers tie a slice row to its marker and its key.
  • Markers on the waveform: click to add a marker, double-click a marker to delete it. The Add/Remove Marker and Slice Selection buttons are gone.
  • Slices land on keys automatically: each new slice takes the next free key from C2 (confirmed); drag a key's slice to another key to move it. “Place slices from…” and “White keys only” are gone. NEW behaviour.
  • Slice table: number, name, play, remove. Click a name to rename the slice in place. A name that is not a valid symbol, or that a project sample this window did not save already uses, gets a red outline and is not applied (row 3 shows it); Save Voicegroup stays disabled until every slice name is usable. Length and the fade toggles are gone. Open: slice-end declick, pending the user's design.
  • Default slice names skip names already in the project (breakbeat_92_snare_2, …), so a fresh split can always be saved without renaming.
  • Envelope: four standard sliders (the Qt Quick Controls Slider the settings page already uses), each with its value. No custom dial.
  • “Rises with each key” is gone. It only matters when one drumkit zone covers several keys: on, each key up plays the sample a semitone higher; off, every key plays it at the same pitch. Each slice gets one key, so the option does nothing here and the Advanced section goes with it.
  • Library: click a file to preview it, double-click to load it. No Preview or Load buttons (same in Edit Sample).
  • Saves to a new voicegroup file, never the song. Save Voicegroup writes the slice samples and a new sound/voicegroups/<name>.inc (plus its include line, and a keysplit table in Keysplit layout). The song, its voicegroup and other songs are untouched, so the “Used by 20 songs” chip and “Save as a copy” toggle are gone. The name defaults to the next free breakbeat_92_kit and gets the same red outline when it is not a valid symbol or names a voicegroup this window did not create. Deferred: saving into the song.
  • Saving again updates the voicegroup and samples this window created. Slice audio unchanged since the last save (only envelope, pan or pitch edited) is not rewritten. If a saved slice's audio changed (markers moved, rate changed), Save asks “Overwrite 2 saved samples?” with the names before writing.
  • Always starts from an empty kit. The Voicegroup line picker is gone; the window no longer reads a kit from the song.
