## Interface contract

- `VoiceEditorState` is a presentation/composition layer over the existing `VoiceListController`. Resolve the selected slot with `voiceDraft(_:)`; do not introduce `VoicegroupPresenter`, duplicate blank-draft rules, or mutate a session directly.
- Editable slots begin from their published `BankVoice`. A blank `.none` slot uses the controller's DirectSound template (key 60, pan 0, first plain sample before phonemes) and all four project-typical ADSR values. Default selection follows the existing `VoiceListSemantics.defaultAdsr` precedence: symbol, family, then the full-sustain fallback.
- Read-only, broken, uncovered, and no-selection states have no editable draft. Retain the existing `BankSlotView.tone` fallback for the list/editor's read-only display. Preserve the native notices and identifiers: `Cry voices are read-only.`, `This voice line couldn't be parsed; it is kept as-is.`, `No voice is defined at this slot.`, and `Select a voice to edit it.`; the read-only notice's QML object name is `voicegroupEditorNotice`.
- The selectable type set matches `kSelectableMacros` in `src/ui/voicegroupbrowser.cpp`: omit `_alt` variants and keysplit from type choices, while retaining a loaded alternate macro. Row visibility follows `setEditorRowsVisible`: symbol for macros taking one, sweep for square 1, duty for square 1/2, period for noise, and ADSR except keysplit/drumkit. Keysplit symbols still resolve through the catalog's keysplit pairs and populate both macro and table.
- Compose the full `BankVoice` without dropping key/pan. Pack/unpack the square-1 sweep time/direction/shift fields and preserve NR10 bit 7. On entering keysplit or drumkit, compose the native reduced voice `{macro, 60, 0, symbol, table}` with no ADSR arguments. A symbol that is not valid for the chosen family falls back to that family's first valid item: first wave, drumkit, or plain sample (then phoneme).
- Track ADSR values per slot and family. `_alt` and no-resample macros share their base family; keysplit/drumkit have no ADSR family. On a family crossing, stash the outgoing quartet, adopt the incoming remembered quartet or its typical values, and clamp CGB A/D/R to 0–7 and sustain to 0–15. When the symbol changes while the displayed envelope still equals the outgoing symbol's typical values, adopt the new symbol's typical values; retain an edited envelope. Clear this per-slot history when the bound `-G` argument changes.
- An unchanged commit is a no-op. Every changed voice goes through `requestVoiceEdit(slot:voice:)`; the owner applies it through `applyVoiceEdit(slot:voice:)`. Preserve the existing `materializesBlank || structuralChange(before:after:)` structural flag: ADSR-only edits stay scalar, family/symbol changes and blank materialization remain structural. Do not create another service/history path.
- `VoicegroupEditor.qml` exposes the existing editor controls with QML object names `editor.notice`, `editor.type`, `editor.symbol`, `editor.sweep`, `editor.duty`, `editor.period`, `editor.adsr`, and `editor.adsr.attack`, `.decay`, `.sustain`, `.release`. The sample-family symbol row is named exactly `editor.sample` for task 8 to replace with its picker. Keep focused ADSR fields from consuming the app's bare Space transport shortcut.
- `VoicegroupEditor.qml` exposes `voiceEditorScrollView` as an object name on a vertical, interactive `Flickable` with clipped content, `contentHeight` tied to the form, and `Flickable.StopAtBounds` behavior matching the existing `SongTabs.qml` scroller. Keep it within the available dock height; never require a 680-pixel-tall host. At widths below 420 logical pixels, move labels above their controls and keep control widths within the assigned column; preserve the frozen control arrangement at 420 pixels and above. Do not propagate an editor minimum/implicit width to the dock: preserve the task-3 root `columnWidth` (default 280), including across CGB/DirectSound selection. The 420×680 size applies only to isolated frozen visual fixtures; task 4 owns the list pin and task 10 the full vanilla/dark editor pin. Golden Sun synth editing/persistence is task 8's extension, not a task-7 acceptance claim.
