## Prerequisites

Task 5's `ProjectService.sampleBrowseData(symbol:auditionKey:)` returns `SampleBrowseResult`. Request `auditionKey: 60` and resolve only the loaded group's direct `table[60]` entry; never walk a nested split. `.playable(SampleBrowseData)` is returned only for a valid DirectSound PCM leaf with positive-size data or a programmable-wave leaf with its 16-byte payload. `.refused` covers unknown/unavailable sources, invalid/overflow indices, nested splits, missing payloads, CGB square/noise leaves, and other unsupported tones; it starts no audition and is not a user-facing operation error. Genuine project/loader failures remain service errors. Task 5 also supplies `VgSynthDefEntry` catalog data and the `DocumentSession` bank/rebind/save contract. Task 7's `VoiceEditorState`, `VoicegroupEditor.qml`, and `editor.sample` row are prerequisites. This task runs after tasks 5–7 and is serialized at all shared Swift/QML/check/visual files.

## Interface contract

- Picker contents come from the existing `VoiceListController` choices and task 5 catalog: sample-family destinations list keysplit groups, then plain samples, then phonemes (using the native `Phoneme` match); wave-family destinations list only programmable waves and show full symbols, not truncated labels. Search filters without changing symbols. Preserve the frozen sample picker object/region name `vgSamplePickerList`.
- Highlight is preview-only. For a sample/wave destination, use its destination ADSR (raw DirectSound values; wave A/D/R masked with `& 7` and sustain with `& 15`) and call the existing `NativeAudio.auditionSample(samples:frequency:loopStart:looped:key:adsr:toneKey:)` or `auditionWave(wave16:key:adsr:)`. Stop with `auditionSampleOff()` on popup close, deselection, or destination change. No bank edit occurs on highlight or first click; the explicit second click/Return commits once through the existing editor/controller pipeline.
- For keysplit rows, request `sampleBrowseData(symbol:auditionKey:)` at key 60 and switch on `SampleBrowseResult`: only `.playable(SampleBrowseData)` starts audio; `.refused` makes no preview and raises no operation error. Resolve the loaded group's single `table[60]` entry only; never recurse through nested splits. A playable DirectSound PCM leaf calls `NativeAudio.auditionSample` at MIDI 60 with child `key` as `toneKey` and child ADSR; a playable 16-byte programmable-wave leaf calls `auditionWave` at MIDI 60 with child ADSR and no `ToneData` key. Stop playable previews on close/deselect; let genuine project/loader failures follow the existing error path.
- Sample commit changes only the bank voice, leaves the song document clean, marks the bank dirty, and is undoable to the exact prior voice. A typed but unlisted symbol can still be committed with Return and undone; it must not be silently replaced by the first listed symbol.
- Wave mode lists complete wave symbols and 16-byte payloads. Preview is a real wave audition with the destination CGB envelope; commit changes both macro and symbol. Undo restores the wave choice, then a second undo restores the original DirectSound family.
- The Golden Sun pseudo-type is available only for the DirectSound family. Drafts resolve the descriptor from the saved catalog or this session's pending registry; render waveform and its parameters, plus pulse LFO controls only for waveform 0. Switching into synth adopts the project's first synth definition or `VgSynthDesc{}` (50%-square pulse); selecting a saved definition keeps its symbol. Editing any of base duty, duty step, modulation depth, phase, or waveform updates the descriptor-named symbol and the loaded bank, not disk.
- Minting reuses a value-equal on-disk definition first, then a pending definition; otherwise generate the native parameter-named `DirectSoundSynth_GoldenSun_...` symbol with `_Saw`/`_Triangle` suffix as appropriate and the native `_2`, `_3`, … collision suffix against saved synths and DirectSound symbols. A pulse switch from a non-pulse waveform adopts `VgSynthDesc{}` rather than a DC-silent inherited descriptor. If the symbol cannot be minted, leave the draft unchanged and surface the native creatable-gate failure.
- Pending definitions remain in `DocumentSession`, are not written or listed as saved choices before save, and save includes only definitions referenced by current bank slots, deduplicated by symbol/descriptor. A clean bank receipt removes exactly those saved pending definitions; a dirty/no-bank receipt removes none. The bridge must preserve the current zero-definition save behavior.
- The synth live-bank predicate uses the actual applied bank lease, not a decoded symbol or a mock: for descriptor `{waveform: 0, baseDuty: 0x21, dutyStep: 0x43, modDepth: 0x65, phase: 0x87}`, assert a zero-size wav descriptor, voice name equal to its generated symbol, and engine payload bytes `[1...5] == [0, 0x21, 0x43, 0x65, 0x87]`. Undo each synth edit back to the original voice; the post-undo clean save leaves both voicegroup bytes and the already-saved synth-definition bytes unchanged.
- `SamplePicker.qml` uses the existing fixture pin names: `vgSamplePickerSearch`, `vgSamplePickerDetail`, `vgSamplePickerList`, `picker.section.N`, `picker.row.<symbol>`, `.type-icon`, and `.loop-badge`. Preserve the full existing 21-region samplepicker sets, including loop badges, rather than a reduced list-only capture.

1. Extend the save bridge and `DocumentSession` pending registry. Forward only current-bank-referenced pending definitions; preserve exact clean/dirty receipt behavior and the existing no-definition path.
2. Extend task 7's `VoiceEditorState` for saved/pending synth descriptors, native mint/reuse/collision rules, waveform and parameter changes, and the pulse DC-silence guard. Apply every committed result via the existing `VoiceListController` intent and `DocumentSession` undoable bank edit.
