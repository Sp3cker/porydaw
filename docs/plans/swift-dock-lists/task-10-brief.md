# Interface contract

- New and Edit are outward actions from the existing `VoiceListController`; the workspace owns the pending slot and selected document. New Sample with an initiating slot commits and then assigns through that slot's existing `applyVoiceEdit`/`DocumentSession.applyBankEdit` path. The sample file commit and bank assignment are separate outcomes: a later assignment failure does not delete or pretend to roll back a committed sample. New Sample without a slot only registers the sample. Edit Sample updates the registered sample and never mutates the bank slot.
- `ProjectService` calls `pd_service_probe_samples()`, `pd_service_read_sample(name:)`, and `pd_service_commit_sample(name:wavBytes:sidecar:removeSidecar:update:)` on the existing worker. Their C ABI values preserve probe support/refusal and sample-directory data; canonical WAV bytes/path plus sidecar-loaded state; and commit status plus `sidecarSaved`/`sidecarError`. Probe also supplies registered sample names and symbols for inline validation; commit remains authoritative. In `pd_service_commit_sample`, register/update through `SampleRegistrar`, then call `DecompProject::rebuildVoicegroupProject`, then write/remove the sidecar. If the rebuild fails after the sample write, return an operation error and do not mutate the sidecar or assign the bank slot; do not roll back the written sample. Sidecar failure after a successful rebuild remains a sidecar warning. Swift/QML never writes project files.
- **New sample flow:** reject a closed/busy project; probe through `pd_service_probe_samples` before showing an audio `FileDialog`; retain the native filters for WAV, AIFF/AIF, MP3, FLAC, OGG, and SF2. Cancellation at file selection, SF2 zone selection, stereo prompt, or editor close performs no commit and no bank edit. Decode by content through task 11's `importAudio(bytes:sourcePath:leftChannelOnly:)`, not the filename extension. If stereo is phase-cancelling, offer the native left-channel-only re-import. For SF2, parse with `readSoundFont(bytes:sourcePath:)`, present the real zone catalog, extract the selected zone with `extractZone(_:index:)`, and persist its zone index in the sidecar. Show the returned probe refusal for unsupported/missing `sound/direct_sound_data.inc` and legacy `aif2pcm` projects.
- The new-name field accepts only `[a-z0-9_]+`; use the worker-provided names/symbols to reject collisions inline, then revalidate on `pd_service_commit_sample`. Commit through compiled `SampleRegistrar::registerSample`; it writes the actual task 11 `writeWav(_:)` result and one registration block. Do not duplicate decoding, resampling, loop, or quantization logic in QML.
- **Edit sample flow:** only an existing DirectSound symbol backed by a registered `.wav` is editable. Read through `pd_service_read_sample(name:)`. If a sidecar exists and its SHA-256 matches the original source bytes, re-import that source with the saved left-only/SF2-zone choices and restore its `SampleEditParams`. If the source is missing, changed, or cannot be re-imported, use the committed 8-bit `.wav` as the canonical fallback; on commit remove stale sidecar data. The sample name is fixed/read-only and the action reads “Save Sample”.
- The sample-name and rate controls preserve their native contracts: `sampleNameEdit` starts with the imported suggested name; collisions and invalid grammar disable `sampleAddButton` and show `sampleNameStatus`, while a valid replacement name enables commit. Editing `sampleRateCombo` text does not commit per keystroke; Return commits the target rate, and the source-rate preset restores the imported sample rate.
- Keep the editor at the native 900x640 visual pin size. Its QML region mapping must cover the existing native regions: `waveform`, four crop/loop handles, `waveform.seam`, `splitter`, `button-box`, and the stable controls `sampleNameEdit`, `sampleLoopOn`, `sampleLoopBody`, `sampleSeamBadge`, `sampleBaseKey`, `sampleAuditionPlay`, `sampleRateCombo`, `sampleFineTune`, `sampleNormalizeMode`, and `sampleAddButton`.
- After successful New, refresh the sample/catalog projection before assigning `DirectSoundWaveData_<name>` to the initiating slot. If its current macro is `DirectSound`, `DirectSoundNoResample`, or `DirectSoundAlt`, preserve that voice and replace only its symbol; otherwise create the native default DirectSound voice (key 60, pan 0), deriving ADSR through `VoiceListSemantics.defaultAdsr(_:macro:symbol:)` from `catalog.typicalAdsr` converted to `VoiceListAdsrDefaults`, with `macro: BankVoiceMacro.directSound` and `symbol: "DirectSoundWaveData_" + name`. Apply the assignment as one normal bank undo command. Edit Sample changes the existing registered WAV/sidecar only and leaves its voice symbol and bank history untouched.
