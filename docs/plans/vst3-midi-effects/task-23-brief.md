# Implementation steps
1. Replace synchronous Payload field QByteArray copies with bounded borrowed views. Keep an owned NUL-terminated string only at C API boundaries that require it (a path preceding UID is not NUL-terminated). Never retain field views beyond Frame.
2. Serialize fixed callback/Ready/reply fields with stack bytes and borrowed output spans rather than allocating QByteArray layers. State replies serialize the required state bytes without copies into multiple owning arrays. Preserve exact limits and empty payloads.
3. Reuse one helper-owned SDK MemoryStream for repeated state/digest reads through a focused subclass that resets protected logical size/cursor/allocationError while retaining normal capacity. Delegate all stream I/O to the pinned SDK; no custom IBStream, SDK patch or new exported API. A state rejected above the existing bridge limit must release its oversized capacity with public SDK setSize(0) before returning the same error. Share canonical getState success/kNotImplemented policy with the existing ABI getter, whose detached owned-buffer contract remains unchanged. Host control ownership excludes concurrent use. A shorter/empty/unsupported snapshot must never include old bytes.
4. Move the factory's returned ClassInfos vector, then erase non-audio classes in place preserving order; classInfos() RETURNS A VALUE, never borrow its temporary. Copy the SDK subcategory sequence directly into the fixed ABI char buffer, preserving pipe joins and exact C-string truncation, rather than allocating subCategoriesString(). Capture provider diagnostics through a local fixed-prefix ostream streambuf sized to pdph_error.message: consume/discard overflow successfully, distinguish any emitted bytes from C-string emptiness, preserve fallback/RAII and publish only on failure. No unbounded error stream or disposable str() copy. In scanner JSON, append escaping, UID hex and decimal fields into one owned output string, preserving all-or-nothing stdout, C++17, JSON escaping and exact numeric/UID format.
5. Remove the remaining shortcut conversion vector by streaming decoded strokes directly into the canonical key registry through a synchronous nonescaping function-pointer reader. Its declaration must state the once-per-index, ascending-order reader contract. Keep wire decoding in host_control, installation/validation in keys, and the exported pointer/count ABI by adapting it to the same kernel. Never use std::function, byte-buffer casts, unaligned typed pointers, fixed arbitrary limits, two-phase public mutation or a second registry. Replace editorWindows' vector snapshot with QVarLengthArray<uintptr_t, 1>: one editor is the normal per-helper invariant, while overflow retains existing multi-editor snapshot semantics. Migrate its private declaration/Mac consumer; no ordering/key policy change. Preserve ABI/state/scan behaviors; add only discriminating state/escaping coverage if needed through existing fixtures. Report any remaining avoidable native host-owned allocation.
6. Scanner failure-line normalization must not allocate a std::string for bounded ABI diagnostics. Use inline character storage sized from pdph_error.message with overflow support for longer exception text; preserve complete CR/LF-to-space normalization, one terminal newline and one atomic stdio publication. No truncation, arbitrary cap or per-character I/O.
