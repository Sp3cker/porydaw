Scope limitations
The 138 original assertion sites are covered, not every behavior of the former
C++ implementation. Swift continues to preserve moved note IDs and original
note-end form, unlike legacy absolute-pitch reminting/canonicalization. An
absolute-pitch request acting only on unterminated notes does not create an
empty undo command in Swift. Neither distinction is observed by these sites;
no exhaustive implementation or native differential parity is claimed.

file correspondence ledger with verbatim original setup, assertions and exact
replacement predicates. Splitting it would obscure original ordering. Movement
planning is separate from atomic collision/commit machinery; history owns merge
eligibility and cancellation policy. No touched Swift file exceeds 600 lines.
