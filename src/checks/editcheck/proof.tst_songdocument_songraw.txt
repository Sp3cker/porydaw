Corpus and fixture sequence
runRawEventOriginalChecks delegates discovery to coreEditCorpusSongs in
tst_songdocument_runner.swift, which enumerates every staged sound/songs/midi/*.mid file,
including unregistered MIDI, matching original playable-file discovery. It rejects
an empty corpus. Each row reads MIDI bytes directly, as SongDocument.load does;
no bank/voicegroup is needed. Each checked-in midi.cfg row must have the source
fixture shape -E -R50 -G<voicegroup> -V100; unexpected flags or duplicate/missing
rows fail rather than silently defaulting. This maps the fixture config exactly
(exactGate true, reverb 50, volume 100, source voicegroup, all other defaults).
Each filename runs both scenarios on separate freshly decoded SongDocuments.
Read/parse failure fails the suite; no MIDI row is skipped.
Select track-0 mapped chunk, else first nonempty chunk, else chunk 0 if present.
Channel is the first channel event or zero. distantBase = max chunk endTick +
100 * max(1, division / (24 * (extendedClocks ? 2 : 1))).
Mutation uses distantBase+100: CC7=64 insert, same-tick CC7=99 modify, move to
tick zero, delete, extend end by 500, clamp end to last event, undo to baseline.
Reordering uses distantBase+1100: CC7=1, CC10=2, note60 velocity100, same tick;
query controller/note bounds, swap controllers, attempt both forbidden moves,
undo/redo swap, then undo/replay all edits and compare exact encoded bytes.
Shared predicates: eventIndex is firstIndex(of:); eventCount filters equality;
tracksSorted tests adjacent tick order on every chunk, as the native helper does.

History-count observation
Swift has no public QUndoStack count accessor. At the tip of a fresh document-only
history, coreEditHistoryCountAtTip counts successful public undo steps, then redoes
all steps. It asserts equal traversal counts and exact restored SongState and
DocumentIdentity. This measures the same entry count before and after forbidden
moves without adding test-only production APIs. Traversal is additional evidence
and leaves the original reorder sequence at the same state and history cursor.
