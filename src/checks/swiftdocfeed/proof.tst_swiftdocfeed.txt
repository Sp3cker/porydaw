Execution and ownership
SwiftDocFeedTest drives SwiftGridDocumentFeed and SwiftGridSessionFeed with
C++ Capture/SessionCapture deliveries; the shared compareDocument and
compareSession helpers assert every payload field against the live
document/view on each delivery. Swift entry point sgd_check_swift_guard runs
runDocumentFeedCheck (S001..S016) and runSessionFeedCheck (S017..S032) against
synthetic endpoints; only the actualSwiftReceiverGuard leg executes them. No
shared Swift fixture file carries expects; swiftcore report.expect*
predicates belong to other lanes' proofs and are not inventoried here.

Fixture, sequence and row constraints
Delivery-count chains (1..13) pin one push per model transition: set, extend,
and clear note selection; primary-track and time-selection transitions
(lanes track 0/controller 7 and track 1/controller 21, tempo true); mute/solo
round-trips. Revision chains pin document.revision()+N across velocity edit,
undo, and redo. Post-undo reconciliation requires a deleted note's token to
die with the next push while undoing the delete does not resurrect delivery;
stale-token intents submit through sgc_ as REJECTED_INVALID without mutation.
Teardown legs require no delivery after clear/destroy and fresh ids on
remount. The unsigned-tick leg pins raw signature precedence rows and
0x80000010 on-tick values.

Original setup, branch guards and helper implementations at the reference
revision remain authoritative; this inventory does not replace those sources.

  struct SessionCapture {
      int deliveries = 0;
      SgsSessionState state{};
      std::vector<uint64_t> noteIds;
      std::vector<SgsLane> lanes;

      static void receive(const SgsSessionState *incoming, const uint64_t *ids,
                          const SgsLane *incomingLanes, void *context)
      {
          auto &capture = *static_cast<SessionCapture *>(context);
          ++capture.deliveries;
          capture.state = *incoming;
          capture.noteIds.clear();
          capture.lanes.clear();
          if (incoming->selectedNoteCount)
              capture.noteIds.assign(ids, ids + incoming->selectedNoteCount);
          if (incoming->timeSelection.laneCount)
              capture.lanes.assign(incomingLanes, incomingLanes + incoming->timeSelection.laneCount);
      }
  };
