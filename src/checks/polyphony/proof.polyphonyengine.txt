Fixture, sequence and row constraints
EngineFixture inits the M4A engine at 48 kHz, installs a 128-voice square
test voicegroup (plus/minus 100, attack 255, sustain 255, release 165) and
caps maxPcmChannels at 1 so the four-note overflow song (steal tick 96,
hold 24-216, drop tick 120, tail-cut tick 148; 1000 samples per tick) forces
one steal, one drop and one tail cut. renderSong renders 220000 samples in
500-frame chunks, splits peak energy at the steal sample, and probes shadow
channels once at stealSample + 4000. liveSentinelTick strikes two live notes
with no sequencer clock. The invert slot sets auditionNote before rendering.
The audition slot processes 8 chunks directly. The channelMode slot renders
49 ticks per data row (allNotesOff 0x7B, allSoundOff 0x78).
The Swift counterpart uses 500-frame rendering and the same current-fixture
event ordering, thresholds, flags, and row values. Its note durations (48,
80, 68, 192, and 96 ticks) are duration-table fixed points, so the default
Swift gate matches the native tick schedule here; new durations need audit.
Swift's PlaybackTimeline.build is
nonfailable; its nonempty-event predicates are the build-success observations.
Original helper implementations at the reference revision remain authoritative.

  struct RenderResult {
      float maxBeforeSteal = 0.0f;
      float maxAfterSteal = 0.0f;
      bool shadowOnAfterSteal = false;
  };

  RenderResult renderSong(M4AEngine &engine, const MidiTimeline &timeline)
  {
      TimelinePlayer player;
      player.reset();
      RenderResult result;
      std::array<float, kRenderChunk> left{};
      std::array<float, kRenderChunk> right{};
      const uint64_t stealSample = kStealTick * kSamplesPerTick;
      uint64_t rendered = 0;
      while (rendered < kRenderSamples) {
          player.render(&engine, &timeline, std::span(left), std::span(right), false, 0);
          float peak = 0.0f;
          for (uint32_t index = 0; index < kRenderChunk; ++index)
              peak = std::max({peak, std::fabs(left[index]), std::fabs(right[index])});
          if (rendered + kRenderChunk <= stealSample)
              result.maxBeforeSteal = std::max(result.maxBeforeSteal, peak);
          else
              result.maxAfterSteal = std::max(result.maxAfterSteal, peak);
          rendered += kRenderChunk;
          if (rendered == stealSample + 4000) {
              for (int channel = MAX_PCM_CHANNELS; channel < TOTAL_PCM_CHANNELS; ++channel) {
                  if ((engine.pcmChannels[channel].status & CHN_ON) != 0)
                      result.shadowOnAfterSteal = true;
              }
          }
      }
      return result;
  }
