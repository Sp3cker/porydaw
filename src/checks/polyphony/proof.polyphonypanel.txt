Execution and ownership
The native panel harness is not built: the T7A runtime cutover removed
polyphony/polyphonypanel.cpp from src/checks/CMakeLists.txt and
src/checks/checkcatalog.cpp registers no polycheck entry, so runPolyCheck never
runs. polyphony/polyphonyengine.swift is the only compiled polyphony source; it
executes under swiftcore (PlaybackChecks.swift) and is inventoried separately:
it covers engine counters and the ring, not this panel. Originally PanelFixture
builds a signature timeline (division 24 at 48 kHz, tempo plus time-signature
events, one program-0 note on key 60) and a PolyphonyPanel sized 380x760 with
track name "Brass" on track 2 and voice name "voice_piano" on voice 5. No
Swift entry point executes these panel checks; no Swift counterpart file was
identified.

Fixture, sequence and row constraints
richSnapshot replays three ring events (stolen key 60 by track 4 at tick 96,
tail-cut key 72 at tick 216, live dropped key 67) with steal/tailCut/drop
counters, invert set, and two PCM channel states. resetRebasesLog replaces
that with a single dropped event at tick 48. logCapIs500 starts from one
dropped event then applies ten 60-event bursts against the ring capacity and
requires the 500-row cap. responsiveLayout settles the shown panel, then
walks 180x980 (stacked), 900x600 (wide) and 380x240/380x980 geometries with
QTRY polling; screenshot saves execute only when m_screenshotPath is set.
No data rows expand these sites.
Original setup, branch guards and helper implementations at the reference
revision remain authoritative; this inventory does not replace those sources.

  std::unique_ptr<MidiTimeline> signatureTimeline()
  {
      SmfFile smf;
      smf.format = 1;
      smf.division = kDivision;
      smf.tracks.resize(2);
      smf.tracks[0].events = {meta(0, 0x51, QByteArray("\x07\xA1\x20", 3)),
                              meta(0, 0x58, QByteArray("\x04\x02\x18\x08", 4)),
                              meta(192, 0x58, QByteArray("\x03\x02\x18\x08", 4))};
      smf.tracks[0].endTick = 384;
      smf.tracks[1].events = {event(0, 0xC0, 0, 0), event(0, 0x90, 60, 100), event(24, 0x80, 60, 0)};
      smf.tracks[1].endTick = 384;
      return MidiTimeline::build(smf, kSampleRate);
  }

  AudioEngine::PolySnapshot snapshotWithEvents(std::initializer_list<M4APolyEvent> events,
                                               uint32_t startTotal = 0)
  {
      AudioEngine::PolySnapshot snapshot;
      snapshot.maxPcmChannels = 5;
      uint32_t total = startTotal;
      for (const M4APolyEvent &event : events)
          snapshot.events[total++ % M4A_POLY_EVENT_CAPACITY] = event;
      snapshot.eventTotal = total;
      return snapshot;
  }

  AudioEngine::PolySnapshot richSnapshot()
  {
      AudioEngine::PolySnapshot snapshot = snapshotWithEvents({
          {M4A_POLY_STOLEN, 2, 60, 4, 5, 96},
          {M4A_POLY_TAIL_CUT, 2, 72, 0, 5, 216},
          {M4A_POLY_DROPPED, 1, 67, 1, 0, M4A_POLY_TICK_NONE},
      });
      snapshot.steal[2] = 1;
      snapshot.tailCut[2] = 1;
      snapshot.drop[1] = 1;
      snapshot.invert = true;
      snapshot.pcm[0] = {true, false, 2, 60};
      snapshot.pcm[MAX_PCM_CHANNELS] = {true, false, 4, 72};
      return snapshot;
  }

  struct PanelFixture {

      std::unique_ptr<PolyphonyPanel> panel = std::make_unique<PolyphonyPanel>();

          panel->resize(380, 760);
          panel->setTimeline(timeline.get());
          QStringList trackNames;
          trackNames.reserve(16);

              trackNames.append(QString());

      }

      void showAndSettle()
      {
          panel->show();
          for (int pass = 0; pass < 3; ++pass)
              QCoreApplication::processEvents();
      }
  };
