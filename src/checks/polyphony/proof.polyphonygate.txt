Execution and ownership
The native gate harness is not built: the T7A runtime cutover removed
polyphony/polyphonygate.cpp from src/checks/CMakeLists.txt and
src/checks/checkcatalog.cpp registers no polycheck entry, so runPolyCheck never
runs. polyphony/polyphonyengine.swift is the only compiled polyphony source; it
executes under swiftcore (PlaybackChecks.swift) and is inventoried separately:
it covers engine counters and the ring, not this dock. Originally each gating
slot requires prepareGateWindow: a real MainWindow with an initialized audio
device, otherwise the slot fails with the device message. No Swift entry point
executes these gating checks; no Swift counterpart file was identified.

Fixture, sequence and row constraints
prepareGateWindow constructs the MainWindow, fails closed when m_audioOk is
false, shows the window and processes events. cleanup unchecks the panel
invert box, hides the dock, processes events, then closes the window. No data
rows expand these sites: one execution per slot on a fresh window.
Original setup, branch guards and helper implementations at the reference
revision remain authoritative; this inventory does not replace those sources.

  bool PolyphonyGateTest::prepareGateWindow()
  {
      m_window = std::make_unique<MainWindow>();
      if (!m_window->m_audioOk)
          return false;
      m_window->show();
      QCoreApplication::processEvents();
      return m_window->isVisible();
  }

  void PolyphonyGateTest::cleanup()
  {
      if (!m_window)
          return;
      m_window->m_polyPanel->setInvertChecked(false);
      m_window->m_polyDock->hide();
      QCoreApplication::processEvents();
      m_window->close();
      m_window.reset();
  }
