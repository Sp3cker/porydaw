Execution and ownership
Native ownership only. runThemeLayoutThemeCheck, runThemeLayoutFontCheck,
runThemeLayoutDarkBaseCheck, and runThemeLayoutScaleCheck (all defined in this
file) launch the themecheck, fontcheck, darkbasecheck, and
editor-layout-{12,16,18} lanes. ThemeLayoutTest::init,
ThemeLayoutFontTest::init, and ThemeLayoutDarkBaseTest::init save the
application font, palette, and stylesheet after applying the vanilla theme (or,
for the dark-base suite, after the poison palette plus application init); the
matching cleanup() methods restore them. Value counterparts for the font and
scale suites now execute in Swift (TypographyLayoutChecks.swift) and the
shell-typography QML entry; these three init sites remain native-only until
Main deletes the harness. The suite declarations live in
src/checks/themelayout/tst_themelayout.h; no shared Swift fixture file exists.

Fixture, sequence and row constraints
Each init() site executes before every test method of its suite, so A001 fans
out over every ThemeLayoutTest case (themecheck lane), A002 over every
ThemeLayoutFontTest case (fontcheck lane), and A003 over the
ThemeLayoutDarkBaseTest case (darkbasecheck lane). ThemeLayoutScaleTest has no
init() guard; its base font size arrives via the lane argument instead.
Original setup, branch guards, and helper implementations at the reference
revision remain authoritative; this inventory does not replace those sources.

  {
      constexpr QColor poison(40, 0, 40);
      application.setStyle(QStringLiteral("fusion"));
      auto palette = application.palette();

              palette.setColor(static_cast<QPalette::ColorGroup>(group),

          }

      application.setPalette(palette);
