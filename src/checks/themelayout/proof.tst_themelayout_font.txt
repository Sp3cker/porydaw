original macro/failure site in this file appears below. The file exercises the
typography module (base size, body/mono/table/caption faces, fitted sizing,
note-name face, glyph centering) and layout initialization against the lane's
expected base font size, plus one theme-apply font-restore case. Source context
preserves setup, loops, and guards between assertions verbatim.
MATCHED means a corresponding Swift predicate was identified and would execute;
PARTIAL means a related Swift predicate exists with a stated unproved condition;
GAP means no equivalent Swift assertion is established;

presenter-level Swift check cannot establish. Value and logic contracts on the
typography/layout modules are GAP: a Swift port could establish them, but no
Swift counterpart file covering this suite was identified
(src/checks/editorqml/EditorQmlTests.swift stages fontPx values for QML

are NATIVE. No MATCHED or PARTIAL disposition is claimed anywhere in this file.

Execution and ownership
Native ownership only. runThemeLayoutFontCheck (defined in
src/checks/themelayout/themelayoutcheck.cpp) launches the fontcheck lane with
the expected base size sampled from the application font before
ui::initializeApplication; ThemeLayoutFontTest::init applies the vanilla theme
and saves font/palette/stylesheet. No Swift entry point executes any of this.
Suite declarations live in src/checks/themelayout/tst_themelayout.h; no shared
Swift fixture file exists. The file-local helpers hasTabularNumbers and
resolvedSpace are value instruments, inventoried via the assertions that use
them.

Fixture, sequence and row constraints
No data rows: each case runs once per lane. typographyAndLayoutInitialization
expands A004 and A009 over the same 8-entry spaces table (Zero/0.0 through
Eight/2.0). typographyFaceContracts derives expectedBodySize from the live base
size (qMax(1, qRound(base * 1.125))) and checks every face against it.
fittedTypographyContracts loops heights 1..captionHeight+4, skipping
unfittable heights; A042 fires only when the fitted size is below the caption
size (maximality: size+1 must overflow). The note-name style expectation is
platform-guarded (Regular on macOS, SemiBold elsewhere). The Q_OS_MACOS branch
is a compile-time guard, not a runtime row.
Original setup, branch guards, and helper implementations at the reference
revision remain authoritative; this inventory does not replace those sources.
